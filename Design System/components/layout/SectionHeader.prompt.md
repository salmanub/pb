Standard section heading: a mono reference eyebrow with a short rule, a serif title, and an optional lede. Use it to open every major section so the whole site reads as one structured dossier.

```jsx
<SectionHeader eyebrow="§ 02 · Servicios" title="Dictámenes que se sostienen en sala"
  lede="Cada informe se redacta para resistir el contradictorio." />
```

`align` left/center, `size` sm/md/lg, `onDark` when placed over the ink section.
