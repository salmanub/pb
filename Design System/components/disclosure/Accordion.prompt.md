Hairline-divided FAQ list with a mono index and serif question. Built for the worried-homeowner audience — calm, no chrome.

```jsx
<Accordion defaultOpen={0} items={[
  { q: '¿Cuánto cuesta un dictamen pericial?', a: 'Depende del alcance…' },
  { q: '¿Sirve mi informe ante un juez?', a: 'Sí. Cada dictamen se redacta…' },
]} />
```

`defaultOpen` index (use `-1` for all collapsed).
