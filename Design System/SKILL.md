Read the `readme.md` file within this skill, and explore the other available files.

This is an editorial-forensic brand: Spectral serif (authority) + IBM Plex Sans
(clarity) + IBM Plex Mono (evidence/reference codes), a warm-neutral palette
(ink, bone paper, concrete) with a single oxide-red accent, near-square corners,
hairline borders, restrained motion, and a documentary "dossier" structure
(reference codes, cited data). It serves two audiences at once: the exacting
legal/insurance professional and the worried homeowner.

If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy
assets out and create static HTML files for the user to view — link `styles.css`
for tokens, and mount components from the compiled `_ds_bundle.js` via
`window.VilardellPeritajeForenseDesignSystem_58f0b0`.

If working on production code, copy assets and read the rules here to become an
expert in designing with this brand. Match the content fundamentals (sober,
factual Spanish; never self-proclaim; data over slogans; no emoji).

If the user invokes this skill without any other guidance, ask them what they
want to build or design, ask a few questions, and act as an expert designer who
outputs HTML artifacts _or_ production code, depending on the need.
