## Avez-vous Découvert un Défaut Grave dans votre Nouvelle Propriété ?

L'achat d'un logement est un des plus grands investissements de la vie. Découvrir après la signature des problèmes graves non visibles (humidité structurelle, problèmes de fondation, installations défectueuses) peut être dévastateur. Ce sont les soi-disant **vices cachés**.

La loi vous protège, mais pour pouvoir réclamer avec succès, vous devez démontrer trois choses : que le défaut est grave, qu'il n'était pas visible au moment de l'achat, et surtout, qu'il existait déjà auparavant.

### Le Délai pour Réclamer est Crucial

Il est vital de savoir que le délai légal pour réclamer pour vices cachés dans l'achat d'un logement de seconde main est, en général, de **six mois depuis la livraison**. Pour les constructions neuves, les délais varient selon la Loi d'Aménagement du Bâtiment (LOE). Il est donc fondamental d'agir rapidement.

### Notre Rôle : Documenter le Défaut

Un juge n'est pas un technicien. Pour que votre demande prospère, vous avez besoin d'une preuve objective. Notre rapport pour vices cachés se concentre sur :

1.  **Accréditer la Préexistence :** Nous démontrons que le problème est antérieur à l'achat.
2.  **Démontrer la Gravité :** Nous décrivons pourquoi le défaut rend le logement "inepte pour l'usage".
3.  **Documenter qu'il n'était pas "Apparent" :** Nous justifions pourquoi un acheteur moyen n'aurait pas pu le détecter.
4.  **Valoriser le Coût de Réparation :** Nous quantifions économiquement la correction.
